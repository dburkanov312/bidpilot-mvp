# BidPilot MVP

AI-powered vehicle underwriting platform for auto dealers.

## Current MVP
- VIN / vehicle inputs
- Market value
- Repair estimate
- Auction fees and transport
- Target profit and risk reserve
- SAFE BID
- MAX BID
- Expected profit and bidding room

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Roadmap
Auction integrations, condition-report/photo analysis, market comps, CARFAX, parts pricing, and predicted-vs-actual dealer learning.
